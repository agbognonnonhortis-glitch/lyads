# Logos des fournisseurs de connexion

Demandés explicitement par le propriétaire le 13 septembre 2026. Les PNG sont conservés sans modification, avec proportions préservées par `object-fit: contain`.

- `google.png` : [Google Identity, règles de marque](https://developers.google.com/identity/branding-guidelines), fichier officiel `https://developers.google.com/static/identity/images/g-logo.png`.
- `facebook.png` : [Meta Brand Resource Center](https://www.meta.com/brand/resources/facebook/logo/), téléchargement officiel « Facebook-Brand-Asset-Pack.zip », fichier `Facebook Brand Asset Pack/Logo/Primary Logo/Facebook_Logo_Primary.png`.

Les marques restent la propriété de leurs titulaires.
