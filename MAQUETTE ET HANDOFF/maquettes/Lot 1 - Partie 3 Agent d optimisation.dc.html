Agent d'optimisation

Une recommandation sans justification chiffrée est une injonction. Dans tout ce module, le chiffre qui fonde le diagnostic est au même niveau typographique que l'action proposée — jamais relégué à un détail dépliable.

Deux niveaux, un seul écran
Le débutant et le media buyer lisent la même carte. Ce qui change, c'est la profondeur : l'essentiel — action, trois chiffres, impact, fiabilité — est toujours visible ; le raisonnement — période analysée, volume, seuil de référence, alternatives écartées — est à un clic.
Aucun jargon dans le titre, le jargon exact dans le détail. On ne fait pas deux interfaces, on hiérarchise une seule.
Le groupage est la réponse au volume
Vingt cartes par jour découragent. Quand l'agent propose la même action sur plusieurs objets, une carte-mère porte le diagnostic commun et liste les objets avec une case à cocher chacun : on applique les huit d'un coup ou on en décoche deux.
Effet mesuré sur ce compte : 7 cartes au lieu de 19.
L'historique note l'agent
Chaque action appliquée est confrontée à son estimation : réel contre projeté, sur une même barre. Un agent qui promet 1,72 et livre 1,58 est fiable ; un agent qui promet 1,72 et livre 0,91 doit le montrer.
Un taux de réalisation global est affiché en tête de l'historique. C'est le seul chiffre qui construit la confiance sur la durée.
